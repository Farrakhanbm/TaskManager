# Task Manager

A cross-platform full-stack task management application with a React Native frontend and Node.js/Express REST API backend.

## Overview

Task Manager allows users to create, organize, and track tasks across iOS and Android. Built end-to-end with a normalized relational database, RESTful API, and a responsive mobile UI.

## Features

- **Full CRUD** — Create, read, update, and delete tasks
- **Cross-Platform** — Runs on iOS and Android via React Native
- **Persistent Storage** — MySQL backend with relational schema
- **REST API** — Clean endpoint design with input validation and error handling
- **Status Tracking** — Mark tasks complete, set due dates, and filter by status

## Tech Stack

| Layer | Technology |
|---|---|
| Frontend | React Native |
| Backend | Node.js + Express.js |
| Database | MySQL |
| API Style | RESTful |
